# موقع نواة AI — حزمة جاهزة للرفع

هذه الحزمة هي النسخة الإنتاجية الجاهزة من موقع أكاديمية نواة AI.

## محتويات الحزمة

- `index.html`: الصفحة الرئيسية.
- `assets/`: ملفات JavaScript وCSS المحسنة.
- `nawa-neural-orb.png`: الصورة الرئيسية للموقع.
- `.nojekyll`: ملف مساعد للاستضافة الثابتة.

## طريقة الاستخدام

ارفع **جميع الملفات والمجلدات داخل هذه الحزمة** إلى خدمة استضافة مواقع ثابتة، وليس ملف ZIP فقط، إذا كانت الخدمة تطلب ملفات الموقع مباشرة.

إذا كان الهدف حفظ المشروع على Google Drive فقط، ارفع ملف ZIP كما هو. ولتشغيل الموقع كرابط عام، استخدم خدمة استضافة مواقع ثابتة مثل GitHub Pages أو Netlify أو Vercel، لأن Google Drive لا يشغّل ملفات HTML كموقع عام بشكل مباشر في أغلب الحسابات.

ابدأ التشغيل من الملف `index.html` عند استخدام استضافة ثابتة.
