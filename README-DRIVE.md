# موقع الملابس الذكي — حزمة جاهزة للرفع

هذه الحزمة هي النسخة الإنتاجية الجاهزة من **موقع الملابس الذكي | خزانة**.

## محتويات الحزمة

- `index.html`: الصفحة الرئيسية للمتجر.
- `assets/`: ملفات JavaScript وCSS المحسنة.
- `wardrobe-hero.jpg`: صورة الحملة الرئيسية.
- `wardrobe-look-1.jpg` و`wardrobe-look-2.jpg` و`wardrobe-look-3.jpg`: صور المنتجات.
- `404.html`: صفحة fallback للاستضافة الثابتة.
- `.nojekyll`: ملف مساعد لـ GitHub Pages.

## التشغيل والرفع

ارفع جميع الملفات والمجلدات داخل هذه الحزمة إلى استضافة مواقع ثابتة. إذا كان الهدف حفظ الموقع فقط، ارفع ملف ZIP إلى Google Drive. لتشغيله كرابط عام استخدم GitHub Pages أو Netlify أو Vercel، لأن Google Drive مخصص للتخزين ولا يشغل ملفات HTML كموقع عام بشكل مباشر.

ابدأ التشغيل من الملف `index.html` عند استخدام استضافة ثابتة.
